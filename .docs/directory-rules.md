# ディレクトリ運用ルール

## 基本方針

ホームディレクトリを散らかさない。ファイルは必ず適切な場所に配置する。

## ディレクトリ構成

```
~/
├── CLAUDE.md              # Claude Code の運用ルール (エントリポイント)
├── .scripts/              # 自作スクリプト置き場
├── .docs/                 # 運用ドキュメント置き場
├── .passwords/            # パスワード・認証情報 (gitignore対象)
├── .cache/                # 一時ファイル・インストーラー等
├── デスクトップ/           # XDG デスクトップ
├── ダウンロード/           # XDG ダウンロード
├── ドキュメント/           # XDG ドキュメント
└── (その他 XDG標準)
```

## ルール

1. **スクリプト**: `~/.scripts/` に配置。ホーム直下に `.sh` を置かない
2. **ドキュメント**: `~/.docs/` に配置。運用手順や設定メモはここ
3. **インストーラー/一時ファイル**: `~/.cache/` に移動。用済みなら削除
4. **ホーム直下**: ドットファイル (設定ファイル) と XDG ディレクトリのみ
5. **新規ファイル作成時**: 必ず上記ルールに従って適切なディレクトリに配置
6. **ファイル形式**: Linux 運用関係のファイルは全て Markdown (`.md`) で管理する
7. **パスワード・機密情報**: `~/.passwords/` に配置。`.gitignore` に記載必須
